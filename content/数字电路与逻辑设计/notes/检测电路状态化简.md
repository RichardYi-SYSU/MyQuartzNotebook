# 8421合法码检测

这是一个典型的同步时序逻辑电路的状态化简（State Reduction）过程。

在数字逻辑中，状态化简的核心原则是合并**等价状态**。如果两个状态在**任何相同的输入序列下，都能产生相同的输出序列**，那么这两个状态就是等价的。

我们通常使用等价分类法（集合划分法/分割法）来进行详细推导。其核心思想是：先按输出进行初步分类，然后根据“次态（Next State）是否属于同一个等价类”来不断细化分类，直到分类不能再细化为止。

以下是图片中原始状态转换表化简的详细推导过程：

### 第一步：根据输出相同，进行第一次划分 ($P_1$)

首先观察原始状态表中输入 $X=0$ 和 $X=1$ 时的**输出值**。

* 输出为 `0, 0` 的状态有：S0, S1, S2, S3, S4, S5, S6, S7, S11
* 输出为 `0, 1` 的状态有：S8, S9, S10, S12, S13, S14

根据输出的不同，我们将所有状态划分为两个初始等价类：
$P_1 = \{ \{S_0, S_1, S_2, S_3, S_4, S_5, S_6, S_7, S_{11}\}, \{S_8, S_9, S_{10}, S_{12}, S_{13}, S_{14}\} \}$

为了方便后续推导，我们暂时将这两个集合标记为：

* $G_{1.1} = \{S_0, S_1, S_2, S_3, S_4, S_5, S_6, S_7, S_{11}\}$
* $G_{1.2} = \{S_8, S_9, S_{10}, S_{12}, S_{13}, S_{14}\}$

---

### 第二步：检查次态归属，进行第二次划分 ($P_2$)

接下来，我们检查 $P_1$ 中每个状态在 $X=0$ 和 $X=1$ 时的**次态**分别属于 $G_{1.1}$ 还是 $G_{1.2}$。

1. **检查 $G_{1.2}$ 集合**：
S8 到 S14 的次态全部都是 (S0, S0)。由于 S0 属于 $G_{1.1}$，这意味着 $G_{1.2}$ 中所有元素的次态都指向 $(G_{1.1}, G_{1.1})$。它们步调一致，**不分裂**。
2. **检查 $G_{1.1}$ 集合**：
* $S_0 \rightarrow (S_1, S_2)$，均属于 $G_{1.1}$，指向 $(G_{1.1}, G_{1.1})$
* $S_1 \rightarrow (S_3, S_4)$，均属于 $G_{1.1}$，指向 $(G_{1.1}, G_{1.1})$
* $S_2 \rightarrow (S_5, S_6)$，均属于 $G_{1.1}$，指向 $(G_{1.1}, G_{1.1})$
* $S_7 \rightarrow (S_0, S_0)$，均属于 $G_{1.1}$，指向 $(G_{1.1}, G_{1.1})$
* $S_{11} \rightarrow (S_0, S_0)$，均属于 $G_{1.1}$，指向 $(G_{1.1}, G_{1.1})$
* **$S_3 \rightarrow (S_7, S_8)$**，$S_7 \in G_{1.1}, S_8 \in G_{1.2}$，指向 **$(G_{1.1}, G_{1.2})$** （产生分裂！）
* **$S_5 \rightarrow (S_{11}, S_{12})$**，$S_{11} \in G_{1.1}, S_{12} \in G_{1.2}$，指向 **$(G_{1.1}, G_{1.2})$**
* **$S_4 \rightarrow (S_9, S_{10})$**，$S_9, S_{10}$ 均属于 $G_{1.2}$，指向 **$(G_{1.2}, G_{1.2})$** （产生分裂！）
* **$S_6 \rightarrow (S_{13}, S_{14})$**，$S_{13}, S_{14}$ 均属于 $G_{1.2}$，指向 **$(G_{1.2}, G_{1.2})$**



根据次态去向的不同，$G_{1.1}$ 被分裂成三个子集。由此得到第二次划分：
$P_2 = \{ \{S_0, S_1, S_2, S_7, S_{11}\}, \{S_3, S_5\}, \{S_4, S_6\}, \{S_8, S_9, S_{10}, S_{12}, S_{13}, S_{14}\} \}$

---

### 第三步：基于新类别继续检查，进行第三次划分 ($P_3$)

由于产生新的分类，我们需要重新用 $P_2$ 的类别给集合命名并检查次态去向：
令：$G_{2.1}=\{S_0, S_1, S_2, S_7, S_{11}\}$，$G_{2.2}=\{S_3, S_5\}$，$G_{2.3}=\{S_4, S_6\}$，$G_{2.4}=\{S_8...S_{14}\}$。

1. **检查 $G_{2.2}, G_{2.3}, G_{2.4}$**：
经过验证，它们内部各状态的次态均指向相同的 $G_{2.x}$ 集合对，步调一致，**不分裂**。
2. **检查 $G_{2.1}$ 集合**：
* $S_0 \rightarrow (S_1, S_2)$，均属于 $G_{2.1}$，指向 $(G_{2.1}, G_{2.1})$
* $S_7 \rightarrow (S_0, S_0)$，均属于 $G_{2.1}$，指向 $(G_{2.1}, G_{2.1})$
* $S_{11} \rightarrow (S_0, S_0)$，均属于 $G_{2.1}$，指向 $(G_{2.1}, G_{2.1})$
* **$S_1 \rightarrow (S_3, S_4)$**，$S_3 \in G_{2.2}, S_4 \in G_{2.3}$，指向 **$(G_{2.2}, G_{2.3})$** （产生分裂！）
* **$S_2 \rightarrow (S_5, S_6)$**，$S_5 \in G_{2.2}, S_6 \in G_{2.3}$，指向 **$(G_{2.2}, G_{2.3})$**



由于 S1、S2 的次态去向与 S0、S7、S11 不同，集合再次分裂：
$P_3 = \{ \{S_0, S_7, S_{11}\}, \{S_1, S_2\}, \{S_3, S_5\}, \{S_4, S_6\}, \{S_8, S_9, S_{10}, S_{12}, S_{13}, S_{14}\} \}$

---

### 第四步：继续检查，进行第四次划分 ($P_4$)

令 $P_3$ 中最前面的集合为 $G_{3.1}=\{S_0, S_7, S_{11}\}$，我们重点检查它，因为其他集合在上一轮已经证明稳定。

* **$S_0 \rightarrow (S_1, S_2)$**，此时 S1, S2 已经被独立成了一个新的集合 $\{S_1, S_2\}$。所以 S0 指向的是 **$(\{S_1, S_2\}, \{S_1, S_2\})$**。
* $S_7 \rightarrow (S_0, S_0)$，S0 在当前集合 $G_{3.1}$ 中。指向 $(G_{3.1}, G_{3.1})$。
* $S_{11} \rightarrow (S_0, S_0)$，指向 $(G_{3.1}, G_{3.1})$。

由于次态去向的集合不同，$G_{3.1}$ 被彻底拆分：
$P_4 = \{ \{S_0\}, \{S_7, S_{11}\}, \{S_1, S_2\}, \{S_3, S_5\}, \{S_4, S_6\}, \{S_8, S_9, S_{10}, S_{12}, S_{13}, S_{14}\} \}$

---

### 第五步：验证稳定性，得出最终等价类

基于 $P_4$ 再次检查所有集合的次态去向，你会发现：

* $\{S_1, S_2\}$ 次态分别去 $\{S_3, S_5\}$ 和 $\{S_4, S_6\}$，步调一致。
* $\{S_3, S_5\}$ 次态分别去 $\{S_7, S_{11}\}$ 和 $\{S_8 \dots\}$，步调一致。
* 以此类推，没有任何集合会再发生分裂。

**划分结束！最终的等价类就是 $P_4$ 的集合：**

1. 类 A：$\{S_0\}$ -> 用 **S0** 作为代表
2. 类 B：$\{S_1, S_2\}$ -> 取 **S1** 作为代表，意味着 $S_1 \equiv S_2$
3. 类 C：$\{S_3, S_5\}$ -> 取 **S3** 作为代表，意味着 $S_3 \equiv S_5$
4. 类 D：$\{S_4, S_6\}$ -> 取 **S4** 作为代表，意味着 $S_4 \equiv S_6$
5. 类 E：$\{S_7, S_{11}\}$ -> 取 **S7** 作为代表，意味着 $S_7 \equiv S_{11}$
6. 类 F：$\{S_8, S_9, S_{10}, S_{12}, S_{13}, S_{14}\}$ -> 取 **S8** 作为代表，意味着这 6 个状态完全等价

---

### 结论：生成化简后的状态表

现在，我们把等价的代表态代回到原始表格中（将 S2 写成 S1，S5 写成 S3，S6 写成 S4... 以此类推），就得到了图中**右上角“化简得”的表格**：

* **S0** 原始次态是 S1 和 S2。因为 S2=S1，所以次态变成 **S1, S1**。
* **S1** 原始次态是 S3 和 S4。没有被合并掉，保持 **S3, S4**。
* **S3** 原始次态是 S7 和 S8。保持 **S7, S8**。
* **S4** 原始次态是 S9 和 S10。因为 S9=S8 且 S10=S8，所以次态变成 **S8, S8**。
* **S7** 原始次态是 S0 和 S0。保持 **S0, S0**。
* **S8** 原始次态是 S0/0 和 S0/1。保持 **S0/0, S0/1**。

最后一步，为了电路设计的字母规范，将保留下来的状态重新赋名为 A, B, C, D, E, F （即图片右下角的替换表），就完成了整个状态化简与分配方案的推导。


# 111 序列的检测（只检测一种串行输入）

比如111

设计一个检测“111”串行输入的序列检测器，最经典的思路是设计一个允许重叠检测（Overlapping）的 Mealy 状态机。也就是说，如果输入序列是 `1111`，输出应该是 `0011`（第三个和第四个 '1' 都能构成独立的 "111" 序列）。

为了展示**状态化简**的过程，我们先用一种“非最简（无脑记录历史）”的方式建立原始状态表，然后再通过等价分类法把它化简成最简状态图。

---

### 第一阶段：建立原始（冗余）状态表

假设我们使用一个移位寄存器的思路，只记录**最后接收到的 2 个输入位**作为当前状态。
我们可以定义 4 个初始状态：

* **$S_{00}$**：最后两位是 00（或初始启动状态）
* **$S_{01}$**：最后两位是 01
* **$S_{10}$**：最后两位是 10
* **$S_{11}$**：最后两位是 11

**原始状态转换表（Mealy型）：**

| 当前状态 | $X=0$ (次态 / 输出) | $X=1$ (次态 / 输出) |
| --- | --- | --- |
| **$S_{00}$** (00) | $S_{00}$ / 0 | $S_{01}$ / 0 |
| **$S_{01}$** (01) | $S_{10}$ / 0 | $S_{11}$ / 0 |
| **$S_{10}$** (10) | $S_{00}$ / 0 | $S_{01}$ / 0 |
| **$S_{11}$** (11) | $S_{10}$ / 0 | $S_{11}$ / **1** |

*(注：只有在当前状态为 $S_{11}$ 且再次输入 1 时，意味着凑齐了 "111"，此时输出 1。)*

---

### 第二阶段：状态化简（等价分类法）

我们要找出在任何输入下，次态和输出都等价的状态并进行合并。

**第一步：按输出分类 ($P_1$)**
观察四种状态的输出 $(Z_{x=0}, Z_{x=1})$：

* $S_{00}, S_{01}, S_{10}$ 的输出都是 `(0, 0)`
* $S_{11}$ 的输出是 `(0, 1)`

由此得到第一次划分：
$P_1 = \{ \{S_{00}, S_{01}, S_{10}\}, \{S_{11}\} \}$
*(我们标记第一类为 $G_1$，第二类为 $G_2$)*

**第二步：检查次态归属，进行分裂 ($P_2$)**
重点检查 $G_1 = \{S_{00}, S_{01}, S_{10}\}$ 内部状态的次态去向：

* **$S_{00} \rightarrow (S_{00}, S_{01})$**，次态都在 $G_1$ 内部，去向为 **$(G_1, G_1)$**。
* **$S_{10} \rightarrow (S_{00}, S_{01})$**，次态都在 $G_1$ 内部，去向为 **$(G_1, G_1)$**。
* **$S_{01} \rightarrow (S_{10}, S_{11})$**，$S_{10} \in G_1$ 但 $S_{11} \in G_2$，去向为 **$(G_1, G_2)$**。（**产生分裂！**）

因为 $S_{01}$ 的次态去向与另外两个不同，$S_{01}$ 被独立出来：
$P_2 = \{ \{S_{00}, S_{10}\}, \{S_{01}\}, \{S_{11}\} \}$

**第三步：再次验证 ($P_3$)**
检查剩下的集合 $\{S_{00}, S_{10}\}$：

* $S_{00} \rightarrow (S_{00}, S_{01})$，此时 $S_{00}$ 在第一类，$S_{01}$ 在第二类。
* $S_{10} \rightarrow (S_{00}, S_{01})$，去向完全一样。

二者步调一致，不再分裂。**化简结束！**

---

### 第三阶段：化简后的状态分配与状态图

我们将等价的 $\{S_{00}, S_{10}\}$ 合并为一个状态。赋予它们新的物理意义：

* **状态 A**（合并了 $S_{00}, S_{10}$）：代表“序列被打断，当前没有连续的1”。
* **状态 B**（原 $S_{01}$）：代表“刚刚收到 1 个 1”。
* **状态 C**（原 $S_{11}$）：代表“已经连续收到 2 个 1”。

**最简状态转换表：**

| 当前状态 | $X=0$ (次态 / 输出) | $X=1$ (次态 / 输出) |
| --- | --- | --- |
| **A (0个1)** | A / 0 | B / 0 |
| **B (1个1)** | A / 0 | C / 0 |
| **C (2个1)** | A / 0 | C / 1 |
