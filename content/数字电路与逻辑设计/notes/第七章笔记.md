
## 锁存器和触发器的区别

|项目|锁存器 Latch|触发器 Flip-Flop|
|---|---|---|
|敏感方式|电平敏感|边沿敏感|
|控制信号|使能 EN|时钟 CLK|
|输出变化|使能有效期间可变化|只在时钟边沿变化|
|是否透明|是|否|
|时序分析|较复杂|较简单|
|常见用途|临时存储、异步逻辑|寄存器、状态机、同步电路|

## 锁存器

### SR锁存器

- S代表Set，为置位端
- R代表Reset，为复位端
- 二者均为0时锁存数据
- 区分NOR型和NAND型
	- NOR型高电平被称为有效信号
	- NAND型相反

### 置位与复位操作

- 置位操作就是让主输出为1
- 复位操作就是让主输出为0

### 工作原理

> 对于XOR型

- 当S=1，R=0时，Q=1，Q'=0
- 当S=0，R=1时，Q=0，Q'=1
- 当S=0，R=0时，Q=0，Q'=0（锁存）
- 当S=1，R=1时，Q=1，Q'=1不允许出现

### D锁存器

- 目的是为了避免SR锁存器中出现的非法情况，即S和R均为1
- 将输入变为单个，一个直接输入，另一个接非门后输入
- 输入为1时代表置位，即让输出为1，输入为0时代表复位，让输出为0
- 此外还添加了门控信号（使能），当EN为0时为锁存状态（保持），为1时才可修改

## 触发器

- 由锁存器的电平敏感变为仅在时钟转换时对输入敏感
- 三角形表示正边沿触发，三角形前有圆形表示负边沿触发

### JK触发器

- J和K没有具体的英文含义
- JK触发器本质是对SR触发器的改进，将SR触发器中两个输入均为1进行改进，现在两个输入均为1时被视作反转操作，即将两个输出端的值进行互换
- 4中情况
	- Toggle 翻转
	- No change 保持
	- Reset 复位
	- Set 置位

### 触发器运算特性

因为实际信号不是瞬间从 0 跳到 1 的，而是有上升/下降过程。

为了统一测量标准，通常规定：

从输入波形到达 50% 电压点开始算，到输出波形到达 50% 电压点结束。

**传输延迟时间**

- 输入信号导致输出发生变化的时间间隔，用二者变化时间的50%点来计算

**建立时间**

- 输入先于时钟触发边沿到达所需的最小时间间隔
- 在时钟有效触发边沿到来之前，输入数据 D 必须提前稳定好的最短时间。

**保持时间**

- 时钟脉冲触发边沿到达后，输入上的逻辑电平需要保持的最小时间间隔

**二者区别**

| 项目   | 建立时间 `t_s` | 保持时间 `t_h` |
| ---- | ---------- | ---------- |
| 位置   | 时钟边沿之前     | 时钟边沿之后     |
| 要求   | D 提前稳定     | D 继续稳定     |
| 违反后果 | 可能采不到正确输入  | 可能采错或进入亚稳态 |
| 记忆方式 | “提前准备好”    | “采完前别急着变”  |

### 触发器应用

**分频**

- n个触发器可使时钟频率除以$2^n$
- 本质利用JK触发器的翻转

**计数**

- 跟分频类似，只不过在中间引出输出

### 单稳态触发器

- 单稳态触发器只有一个稳定态，另一个是暂稳态，一段时间后又会回到稳定态
- 矩形脉冲是一种短时间有效的数字信号；单稳态触发器是一种受到触发后能自动产生一个固定宽度矩形脉冲的电路，它的脉冲宽度主要由 RC 时间常数决定。

**不可重复与可重复触发型**

- 在单稳态触发器已处于暂稳态时，再给予脉冲，输出的时间不会延长
- 反之为可重复触发型
