根据你提供的课程核心讲义、开卷考试复习纲要及典型例题，我为你将全书最常用、最核心的微分与积分公式总结如下。你可以将其直接作为开卷考试的速查指南：

## 一、 电路基本物理量之间的微积分关系

在时域分析中，电流、电压、功率和能量的定义本质上都是通过微积分建立的：

| **物理量关系**   | **微分表达式（求导）**             | **积分表达式**                                | **物理意义与注意点**                                                  |
| ----------- | ------------------------- | ---------------------------------------- | ------------------------------------------------------------- |
| **电荷与电流**   | $i(t) = \frac{dq(t)}{dt}$ | $q(t) = \int_{t_1}^{t_2} i(t) \, dt$     | 电流是电荷的时间变化率 。计算电荷量时，将电流对时间进行定积分 。                             |
| **能量与功率**   | $p(t) = \frac{dw(t)}{dt}$ | $w(t) = \int_{t_0}^{t} p(\tau) \, d\tau$ | 功率是能量的时间变化率，能量是功率对时间的积分 。                                     |
| **电压与瞬时功率** | —                         | $p(t) = v(t) \cdot i(t)$                 | 结合上式，能量亦可写为：$w(t) = \int_{t_0}^{t} v(\tau)i(\tau) \, d\tau$ 。 |

## 二、 核心动态元件的伏安关系（VCR）

电容和电感是电路中的“储能元件”（时域动态电路的基石），它们的电压和电流通过微积分紧密关联 ：

### 1. 电容元件 (Capacitor)

- **微分约束（已知电压求电流）**：
    
    $$i(t) = C \frac{dv(t)}{dt}$$
    
- **积分约束（已知电流求电压）**：
    
    $$v(t) = \frac{1}{C} \int_{t_0}^{t} i(\tau) \, d\tau + v(t_0)$$
    
- **储能公式**：
    
    $$w_C(t) = \frac{1}{2} C v^2(t)$$
    
- **考试必背特性**：在直流电路中，电压不随时间变化（$\frac{dv}{dt}=0$），电容相当于**开路** ；且电容两端的**电压不能跃变** 。
    

### 2. 电感元件 (Inductor)

- **微分约束（已知电流求电压）**：
    
    $$v(t) = L \frac{di(t)}{dt}$$
    
- **积分约束（已知电压求电流）**：
    
    $$i(t) = \frac{1}{L} \int_{t_0}^{t} v(\tau) \, d\tau + i(t_0)$$
    
- **储能公式**：
    
    $$w_L(t) = \frac{1}{2} L i^2(t)$$
    
- **考试必背特性**：在直流电路中，电流不随时间变化（$\frac{di}{dt}=0$），电感相当于**短路** ；且流过电感的**电流不能跃变** 。
    

## 三、 电路分析中最常用的数学微积分公式速查

在实际做题（如分段函数积分、正弦波求导等）时，最常套用的数学公式如下 ：

### 1. 常用求导（微分）法则

- **常数与线性**：$\frac{d}{dt}(C) = 0$ ； $\frac{d}{dt}(kt) = k$
    
- **幂函数**：$\frac{d}{dt}(kt^n) = nkt^{n-1}$
    
- **指数函数**：$\frac{d}{dt}(e^{at}) = a e^{at}$
    
- **三角函数**：$\frac{d}{dt}[\sin(\omega t + \phi)] = \omega \cos(\omega t + \phi)$
    
- **乘积与链式法则（常用于复杂的电荷求电流）**：
    
    - 乘积：$\frac{d}{dt}[f(t)g(t)] = f'(t)g(t) + f(t)g'(t)$
        
    - 链式：$\frac{d}{dt}[f(g(t))] = f'(g(t)) \cdot g'(t)$
        
    - _示例_：$\frac{d}{dt}[5t \sin(4\pi t)] = 5\sin(4\pi t) + 20\pi t \cos(4\pi t)$
        

2. 常用积分公式

- **幂函数积分**：$\int x^n \, dx = \frac{x^{n+1}}{n+1} + C \quad (n \neq -1)$ （例如：$\int 4t^2 \, dt = \frac{4}{3}t^3 + C$ ）
    
- **指数函数积分**：$\int e^{ax} \, dx = \frac{1}{a}e^{ax} + C$
    
- **正弦/余弦项积分（交流功率与电容电压计算高频使用）**：
    
    - $\int \sin(ax) \, dx = -\frac{1}{a} \cos(ax) + C$
        
    - $\int \cos(ax) \, dx = \frac{1}{a} \sin(ax) + C$
        
    - _实际电路代值示例_ ：
        
        $$\int_0^t 5\cos(60\pi \tau) \, d\tau = \left. [cite_start]\frac{5}{60\pi} \sin(60\pi \tau) \right|_0^t = \frac{1}{12\pi} \sin(60\pi t)$$
        

> ⚠️ **开卷大坑提示** ： 在带入具体时间（如 $t = 5\text{ ms}$）计算三角函数值时： * 作为**正弦/余弦内部的相位角**（如 $\sin(60\pi t)$）时，$\pi$ 应代入 **$180^\circ$**（即 $60 \times 180^\circ \times 0.005 = 54^\circ$） 。 * 作为**分母或积分系数**（如 $\frac{1}{12\pi}$）时，$\pi$ 必须代入 **$3.14$** 。
