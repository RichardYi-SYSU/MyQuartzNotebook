# 同步计数器

> 计数器中的所有触发器都由同一个公共时钟脉冲同时计时

2、3、4位同步计数器的JK端都是接的相通型号，本质为了将JK触发器变成T触发器

需要用到的：JK激励表

| $Q_i$ | $Q_i^+$ | $J_i$ | $K_i$ |
| ----- | ------- | ----- | ----- |
| 0     | 0       | 0     | X     |
| 0     | 1       | 1     | X     |
| 1     | 0       | X     | 1     |
| 1     | 1       | X     | 0     |
X的理解：

1. **为了把 1 圈得更大，可以把** X **当 1。**
2. **如果某个** X **对化简没帮助，就不用管它，相当于当 0。**
3. **不能把明确的 0 圈进去。**
4. **圈的大小必须是** 1,2,4,8,16 **个格子。**
5. **目标是让表达式最简单。**

课件中的J=K的形式是把JK触发器当T触发器用

# 同步计数器设计

## 一般模式

所有时序电路都可看作“组合逻辑+存储电路+反馈”的结构

- 如果输出只和状态有关而与输入无关，就叫Moore摩尔型电路
- 如果输出和状态和输入都有关，就叫Mealy米勒型电路
