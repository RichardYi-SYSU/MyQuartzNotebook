
# 聚类分析定义

寻找一组对象，使得同一组内的对象彼此相关，而与不同组内的对象不同

**以下不是聚类分析：**

- 监督分类：已有标签
- 简单划分：按人为规则分组

# K-means

## 流程

先选 K 个中心点，然后让所有点归到最近的中心点，再更新每一类的中心点，不断重复，直到中心点稳定。

```
指定 K
↓
随机初始化 K 个质心
↓
计算每个点到各质心的距离
↓
把点分配给最近的质心
↓
重新计算每个簇的质心
↓
质心是否变化？
    是 → 继续迭代
    否 → 聚类结束
```

# DBSCAN

## 流程

根据密度来聚类，不用初始指定类的数量

1. 给定两个参数：半径和Minpts（在半径内至少需要多少个点，才算密集）`ε = 2 MinPts = 4`则表示如果一个点半径2的范围内有4个点，这个区域就认为是密集的
2. 给所有点打标签：核心点、边界点、噪声点
	- 核心点：如果在一个点的半径范围内，点的数量大于等于Minpts，那么其为核心点
	- 边界点：如果一个点自己周围的点不够多，不是核心点，但是它落在某个核心点的 $\varepsilon$ 邻域内，那么它是边界点。
	- 噪声点：如果一个点既不是核心点，也不在任何核心点的 $\varepsilon$ 邻域内，那么它就是噪声点。
3. 去掉噪声点
4. 连接距离在 ε 内的核心点
5. 连通的核心点形成一个簇
6. 把边界点分配给相关的核心点所在簇

## 与K-means的区别

|**特性**|**K-means (K-均值)**|**DBSCAN (基于密度)**|
|---|---|---|
|**簇的形状限制**|只能处理球形、凸形的数据|可以处理任何不规则形状的数据|
|**聚类数量设定**|必须人为提前指定 $K$ 值|自动发现，无需指定簇的数量|
|**对噪点/异常值的态度**|极其敏感，强行把噪点拉入某个簇中|非常擅长，自动将稀疏点标记为噪点|
|**对数据密度的要求**|能处理密度不同的簇（只要是球形）|很难处理密度差异极大的多个簇|
|**计算速度与数据量**|计算极快，非常适合海量数据|速度相对较慢，大规模高维数据下吃力|
