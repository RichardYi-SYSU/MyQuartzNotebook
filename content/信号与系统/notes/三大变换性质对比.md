
| 类型       | 正变换                                                                     | 反变换 / 展开                                                                                  |
| -------- | ----------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 双边拉普拉斯变换 | $(\displaystyle X(s)=\int_{-\infty}^{\infty}x(t)e^{-st}dt)$             | $(\displaystyle x(t)=\frac{1}{2\pi j}\int_{\gamma-j\infty}^{\gamma+j\infty}X(s)e^{st}ds)$ |
| 傅里叶变换    | $(\displaystyle X(\omega)=\int_{-\infty}^{\infty}x(t)e^{-j\omega t}dt)$ | $(\displaystyle x(t)=\frac{1}{2\pi}\int_{-\infty}^{\infty}X(\omega)e^{j\omega t}d\omega)$ |
| 傅里叶级数    | $(\displaystyle c_k=\frac{1}{T}\int_T x(t)e^{-jk\omega_0t}dt)$          | $(\displaystyle x(t)=\sum_{k=-\infty}^{\infty}c_ke^{jk\omega_0t})$                        |
| 离散傅里叶级数  | $c_k=\frac{1}{N}\sum_{n=0}^{N-1} x[n]e^{-j\frac{2\pi}{N}kn}$            | $x[n]=\sum_{k=0}^{N-1} c_k e^{j\frac{2\pi}{N}kn}$                                         |

| 性质            | 拉普拉斯变换                                                                  | 傅里叶变换                                                                                               | 傅里叶级数                                              |
| ------------- | ----------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| 线性            | $(ax_1(t)+bx_2(t)\leftrightarrow aX_1(s)+bX_2(s))$                      | 同样成立                                                                                                | 同样成立                                               |
| 时移            | $(x(t-t_0)\leftrightarrow e^{-st_0}X(s))$                               | $(x(t-t_0)\leftrightarrow e^{-j\omega t_0}X(\omega))$                                               | $(x(t-t_0)\leftrightarrow c_k e^{-jk\omega_0t_0})$ |
| 频移            | $(e^{s_0t}x(t)\leftrightarrow X(s-s_0))$                                | $(e^{j\omega_0t}x(t)\leftrightarrow X(\omega-\omega_0))$                                            | $乘 (e^{jm\omega_0t})：系数平移 (c_{k-m})$               |
| 时域微分          | $(\frac{dx}{dt}\leftrightarrow sX(s))$；单边形式含初值                          | $(\frac{dx}{dt}\leftrightarrow j\omega X(\omega))$                                                  | $(\frac{dx}{dt}\leftrightarrow jk\omega_0 c_k)$    |
| 时域积分          | $(\int_{-\infty}^{t}x(\tau)d\tau\leftrightarrow \frac{1}{s}X(s))$，需考虑收敛 | $(\int_{-\infty}^{t}x(\tau)d\tau\leftrightarrow \frac{1}{j\omega}X(\omega)+\pi X(0)\delta(\omega))$ | 积分后系数约为 $(\frac{c_k}{jk\omega_0})$，但 (k=0) 要单独处理   |
| 乘以 (t)        | $(tx(t)\leftrightarrow -\frac{dX(s)}{ds})$                              | $(tx(t)\leftrightarrow j\frac{dX(\omega)}{d\omega})$                                                | 不常用，因为 (tx(t)) 通常不再周期                              |
| 卷积            | $(x_1*x_2\leftrightarrow X_1(s)X_2(s))$                                 | $(x_1*x_2\leftrightarrow X_1(\omega)X_2(\omega))$                                                   | 周期卷积 $(\leftrightarrow T c_k d_k)$ 或视定义而定          |
| 时域相乘          | (x_1(t)x_2(t)\leftrightarrow) 频域卷积形式                                    | $(x_1x_2\leftrightarrow \frac{1}{2\pi}X_1*X_2)$                                                     | 系数卷积：$(\displaystyle c_k=\sum_m a_m b_{k-m})$      |
| 实信号对称性        | 依赖 (s) 域共轭对称                                                            | $(x(t)) 实，则 (X(-\omega)=X^*(\omega))$                                                               | $(x(t)) 实，则 (c_{-k}=c_k^*)$                        |
| 初值定理          | 常用：$(\displaystyle x(0^+)=\lim_{s\to\infty}sX(s))$                      | 一般不用                                                                                                | 一般不用                                               |
| 终值定理          | 常用：$(\displaystyle x(\infty)=\lim_{s\to0}sX(s))$，需稳定条件                  | 一般不用                                                                                                | 周期信号通常无终值                                          |
| 系统分析          | 判断稳定性、暂态、零极点、ROC                                                        | 判断频率响应、滤波、频谱                                                                                        | 分析周期信号谐波                                           |
