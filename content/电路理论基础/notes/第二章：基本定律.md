- 注意电导与电阻的区别
  - 在并联电路中$\frac{1}{R}=\frac{1}{R_1}+\frac{1}{R_2}$，$G=G_1+G_2$，电导G=1/R
  - 在串联电路中：$R_{eq} = R_1 + R_2$，等效电导 $G_{eq} = \frac{G_1 G_2}{G_1 + G_2}$（与并联时电阻公式对偶）
- Y型电路与三角形电路电阻互换公式（Δ-Y变换）：
  - **Δ→Y（Delta to Wye）**：
    - $R_1 = \frac{R_b R_c}{R_a + R_b + R_c}$
    - $R_2 = \frac{R_c R_a}{R_a + R_b + R_c}$
    - $R_3 = \frac{R_a R_b}{R_a + R_b + R_c}$
  - **Y→Δ（Wye to Delta）**：
    - $R_a = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_1}$
    - $R_b = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_2}$
    - $R_c = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_3}$
  - 当Y和Δ电路平衡时：$R_Y = R_\Delta / 3$ 或 $R_\Delta = 3R_Y$
