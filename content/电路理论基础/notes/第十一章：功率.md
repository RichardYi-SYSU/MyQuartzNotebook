
## 11.1 瞬时功率和平均功率

### 瞬时功率

正弦稳态下，设 $v(t)=V_m\cos(\omega t+\theta_v)$，$i(t)=I_m\cos(\omega t+\theta_i)$：

$$p(t)=v(t)i(t)=\frac{1}{2}V_mI_m\cos(\theta_v-\theta_i)+\frac{1}{2}V_mI_m\cos(2\omega t+\theta_v+\theta_i)$$

- 第一部分为**常量**（与时间无关）
- 第二部分为正弦函数，频率为 $2\omega$

### 平均功率（有功功率）

$$P=\frac{1}{T}\int_0^T p(t)\,dt=\frac{1}{2}V_mI_m\cos(\theta_v-\theta_i)=V_{rms}I_{rms}\cos(\theta_v-\theta_i)$$

> 令 $\theta = \theta_v - \theta_i$（阻抗角/导纳角），$\cos\theta$ 即为功率因数。
> 就是电压相位-电流相位，二者同相平均功率最大，相差90度则平均功率为0

- **纯电阻**：$P=\frac{1}{2}I_m^2R=\frac{V_m^2}{2R}$，任何时刻均吸收功率
- **纯电抗（L/C）**：$P=0$，平均功率为零，只储能不耗能

## 11.2 最大平均功率传输

### 共轭匹配（负载为阻抗形式）

负载 $Z_L = R_L + jX_L$，戴维南等效 $Z_{Th}=R_{Th}+jX_{Th}$：

$$Z_L = Z_{Th}^* \quad\Rightarrow\quad R_L = R_{Th},\; X_L = -X_{Th}$$

此时最大平均功率：

$$P_{max} = \frac{|V_{Th}|^2}{8R_{Th}}$$
$$p_{max}=\frac{V_{Th}^2}{4R_{th}}$$
- RMS用1/4 峰值用1/8
### 模匹配（负载为纯电阻）

当负载只能为纯电阻 $R_L$ 时：

$$R_L = |Z_{Th}| = \sqrt{R_{Th}^2 + X_{Th}^2}$$

$$P_{max} = \frac{|V_{Th}|^2}{8R_{Th}}\quad\text{（小于共轭匹配时的功率）}$$

| 匹配类型 | 条件 | 适用场景 |
|----------|------|----------|
| 共轭匹配 | $Z_L = Z_{Th}^*$ | 负载可任意调阻抗 |
| 模匹配 | $R_L = \|Z_{Th}\|$ | 负载只能为纯电阻 |

> 直流纯电阻电路中 $R_L=R_{Th}$，是模匹配的特例（$X_{Th}=0$）。

## 11.3 有效值（RMS）

周期信号的有效值等于其**方均根**值：

$$X_{rms} = \sqrt{\frac{1}{T}\int_0^T x^2(t)\,dt}$$

### 正弦信号

$$V_{rms} = \frac{V_m}{\sqrt{2}}, \quad I_{rms} = \frac{I_m}{\sqrt{2}}$$

$$P = V_{rms}I_{rms}\cos(\theta_v - \theta_i)$$

> ⚠️ **作业注意**：本教材如无特别说明，电压源、电流源数值均为**有效值**。

---

## 11.4 视在功率与功率因数

### 视在功率

$$S = V_{rms}\,I_{rms} \quad \text{(单位: V·A)}$$

- 表征发电设备的**容量**，不代表真正消耗的功率

### 功率因数

$$pf = \frac{P}{S} = \cos(\theta_v - \theta_i)$$

- $\theta_v - \theta_i$ 称为**功率因数角**，等于负载阻抗角
- 必须注明**超前**还是**滞后**（指电流对电压）

| pf 类型 | 含义 | 负载特性 |
|---------|------|----------|
| 滞后 (lagging) | $I$ 滞后于 $V$ ($\theta_v > \theta_i$) | 电感性 |
| 超前 (leading) | $I$ 超前于 $V$ ($\theta_v < \theta_i$) | 电容性 |

---

## 11.5 复功率

### 定义

$$\tilde{S} = \frac{1}{2}\dot{V}\dot{I}^* = \dot{V}_{rms}\,\dot{I}_{rms}^* = P + jQ$$

| 符号  | 名称        | 公式                                               | 单位  |
| --- | --------- | ------------------------------------------------ | --- |
| $P$ | 有功功率/平均功率 | $P = \operatorname{Re}(\tilde{S}) = S\cos\theta$ | W   |
| $Q$ | 无功功率      | $Q = \operatorname{Im}(\tilde{S}) = S\sin\theta$ | VAR |
| $S$ | 视在功率      | $S = \|\tilde{S}\| = \sqrt{P^2+Q^2}$             | V·A |

### 物理意义

- **$P$（有功功率）**：传递给负载的平均功率，是唯一**有用的**功率，取决于 $R$
- **$Q$（无功功率）**：电源与电抗负载之间能量交换的度量，取决于 $X$
  - $Q = 0$：电阻性负载（$pf=1$）
  - $Q > 0$：电感性负载（滞后 pf）吸收无功
  - $Q < 0$：电容性负载（超前 pf）发出无功

### 功率三角形

```
S = P + jQ
|S|² = P² + Q²
pf = P / |S| = cosθ
```

与阻抗三角形对应：$Z = R + jX$

---

## 11.6 交流功率守恒

总复功率等于各元件复功率之和：

$$\tilde{S}_{total} = \tilde{S}_1 + \tilde{S}_2 + \cdots + \tilde{S}_N$$

$$P_{total} = P_1 + P_2 + \cdots + P_N$$

$$Q_{total} = Q_1 + Q_2 + \cdots + Q_N$$

> ⚠️ **视在功率不满足直接相加**：$S_{total} \neq S_1 + S_2 + \cdots + S_N$

---

## 11.7 功率因数校正

### 问题

感性负载功率因数滞后且较小 → 需要更大的电流 → 传输损耗大、电费高。

### 方法

在负载两端**并联电容器**，提供无功功率补偿。

$$Q_C = Q_1 - Q_2 = P(\tan\theta_1 - \tan\theta_2)$$

$$C = \frac{Q_C}{\omega V_{rms}^2}$$

其中 $\theta_1$ = 校正前功率因数角，$\theta_2$ = 校正后功率因数角。

### 原理图解

```
校正前:  |S₁| = P/cosθ₁,  Q₁ = P·tanθ₁
校正后:  |S₂| = P/cosθ₂,  Q₂ = P·tanθ₂
并联电容提供: Qc = Q₁ - Q₂
```

> 并联电容不改变有功功率 $P$，只减少电源需提供的无功功率。
> 结果：视在功率降低 → 电流减小 → 传输损耗降低。

## 题型与解题策略

### 题型一：计算各元件的平均功率

**特征**：给定电路，求电源产生的平均功率及各无源元件吸收的平均功率。

**策略**：
1. 用网孔法/节点法求出各支路电流相量
2. 对电压源：$P = \frac{1}{2}\operatorname{Re}(V_s I_s^*)$（$I_s$ 流出正极）
3. 对电阻：$P = \frac{1}{2}I_m^2 R = I_{rms}^2 R$
4. 对 L/C：$P = 0$
5. 验证：$\sum P_{source} = \sum P_{load}$

> 参考：例 11-4

---

### 题型二：最大平均功率传输

**特征**：求 $Z_L$（或 $R_L$）为何值时获得最大功率，并求 $P_{max}$。

**策略**：
1. 求负载端戴维南等效：$V_{Th}$、$Z_{Th}=R_{Th}+jX_{Th}$
2. 判断匹配类型：
   - $Z_L$ 任意 → **共轭匹配**：$Z_L=R_{Th}-jX_{Th}$，$P_{max}=\frac{|V_{Th}|^2}{8R_{Th}}$
   - $Z_L$ 纯电阻 → **模匹配**：$R_L=\sqrt{R_{Th}^2+X_{Th}^2}$
3. 戴维南等效时注意：关掉独立源、保留受控源

> 参考：例 11-5（共轭匹配）、例 11-6（模匹配）
> 作业：11.12、11.19

---

### 题型三：视在功率、功率因数、复功率

**特征**：给定 $v(t)$、$i(t)$ 或 $Z$，求 $S$、$P$、$Q$、$pf$、$Z$ 等。

**策略**：
1. 将 $v(t)$、$i(t)$ 转为相量（注意用有效值还是幅值）
2. 计算复功率：$\tilde{S} = V_{rms} I_{rms}^* = P + jQ$
3. 视在功率：$S = |\tilde{S}|$
4. 有功功率：$P = \operatorname{Re}(\tilde{S})$
5. 无功功率：$Q = \operatorname{Im}(\tilde{S})$
6. 功率因数：$pf = P/S = \cos\theta$，**务必注明超前/滞后**
7. 负载阻抗：$Z = V_{rms}/I_{rms}$

**关键公式速查**：
$$\tilde{S} = V_{rms}I_{rms}^* = I_{rms}^2 Z = \frac{V_{rms}^2}{Z^*}$$

> 参考：例 11-9、例 11-10
> 作业：11.51、11.56

---

### 题型四：功率守恒验证

**特征**：含多个负载/传输线的电路，验证功率关系。

**策略**：
1. 分别计算电源和各负载的复功率
2. 验证 $\tilde{S}_{source} = \sum \tilde{S}_{load}$
3. 分别验证 $P$ 和 $Q$ 的守恒
4. **注意**：$S$ 不满足直接求和

> 参考：PPT 例题（传输线 + 负载）

---

### 题型五：功率因数校正

**特征**：已知原始 pf₁、$P$、$V_{rms}$，求并联电容 $C$ 将 pf 提升到 pf₂。

**策略**：
1. 有功功率 $P$ 不变
2. $Q_1 = P \cdot \tan(\cos^{-1}pf_1)$
3. $Q_2 = P \cdot \tan(\cos^{-1}pf_2)$
4. $Q_C = Q_1 - Q_2$
5. $C = \dfrac{Q_C}{\omega V_{rms}^2}$

> 参考：PPT 两道例题（p61-62, p63-65）
> 作业：11.74
