
## 角度转换

 > 加减法用直角坐标 乘除法用极坐标或指数形式

### 直角坐标->极坐标

- $r=\sqrt{a^2+b^2}$
- $\theta=tan^{-1}\frac{b}{a}$

$$a+jb=r\angle\theta$$

### 极坐标->直角坐标

- $a=r\cos\theta$
- $b=r\sin\theta$

$$r\angle\theta = a+jb$$

### 直角坐标<->指数形式

**欧拉公式：**
$$e^{\pm j\theta}=\cos\theta \pm j\sin\theta$$

**直角坐标 → 指数形式：**
$$a+jb = \sqrt{a^2+b^2}\cdot e^{j\tan^{-1}\frac{b}{a}} = r e^{j\theta}$$

**指数形式 → 直角坐标：**
$$re^{j\theta} = r\cos\theta + j\,r\sin\theta = a+jb$$

### 极坐标<->指数形式

$$r\angle\theta = re^{j\theta}$$

> 极坐标和指数形式本质上等价，指数形式在乘除运算中更便于书写。

## 正弦量与相量的转换

> 时域正弦量 $\xleftrightarrow{\text{变换}}$ 频域相量，这是相量法的核心。

### 正弦量 → 相量

给定正弦量：
$$v(t)=V_m\cos(\omega t+\phi)$$

对应相量（用振幅）：
$$\dot{V}=V_m\angle\phi$$

或（用有效值）：
$$\dot{V}=\frac{V_m}{\sqrt{2}}\angle\phi$$

> ⚠️ **注意**：默认正变换采用 **cosine**。若给出的是 sine，需先转换为 cosine：
> $$\sin(\omega t+\phi)=\cos(\omega t+\phi-90^\circ)$$

### 相量 → 正弦量

给定相量：
$$\dot{V}=V_m\angle\phi$$

还原为正弦量：
$$v(t)=V_m\cos(\omega t+\phi)$$

> 相量中隐含角频率 $\omega$，还原时必须写回 $\omega t$。

## 共轭与倒数

### 共轭 (Conjugate)

| 形式 | 共轭 |
|------|------|
| 直角坐标 $a+jb$ | $a-jb$ |
| 极坐标 $r\angle\theta$ | $r\angle(-\theta)$ |
| 指数形式 $re^{j\theta}$ | $re^{-j\theta}$ |

### 倒数 (Reciprocal)

$$\frac{1}{r\angle\theta} = \frac{1}{r}\angle(-\theta)$$

$$\frac{1}{a+jb} = \frac{a-jb}{a^2+b^2}$$

## 相量四则运算

> 核心原则：加减法用直角坐标，乘除法用极坐标或指数形式。

### 加减法（直角坐标）

$$(a_1+jb_1) \pm (a_2+jb_2) = (a_1 \pm a_2) + j(b_1 \pm b_2)$$

> 若给定极坐标形式，先转为直角坐标再加减：
> $$r_1\angle\theta_1 \pm r_2\angle\theta_2 \quad\rightarrow\quad 先转为直角坐标 \rightarrow 再加减 \rightarrow 如需则转回极坐标$$

**几何意义**：相量加减满足平行四边形法则（与向量相同）。
### 乘法（极坐标 / 指数形式）

**极坐标：**
$$r_1\angle\theta_1 \cdot r_2\angle\theta_2 = r_1r_2\angle(\theta_1+\theta_2)$$

**指数形式：**
$$r_1e^{j\theta_1} \cdot r_2e^{j\theta_2} = r_1r_2\, e^{j(\theta_1+\theta_2)}$$

### 除法（极坐标 / 指数形式）

**极坐标：**
$$\frac{r_1\angle\theta_1}{r_2\angle\theta_2} = \frac{r_1}{r_2}\angle(\theta_1-\theta_2)$$

**指数形式：**
$$\frac{r_1e^{j\theta_1}}{r_2e^{j\theta_2}} = \frac{r_1}{r_2}\, e^{j(\theta_1-\theta_2)}$$

### 乘除特例

| 运算 | 效果 |
|------|------|
| 乘以 $j$ | 逆时针旋转 $90^\circ$（$j=1\angle 90^\circ$） |
| 除以 $j$（即乘以 $-j$） | 顺时针旋转 $90^\circ$（$-j=1\angle -90^\circ$） |
| 乘以 $-1$ | 旋转 $180^\circ$（反向） |

> $j$ 的本质就是 $90^\circ$ 旋转因子：$j \cdot (a+jb) = -b + ja$

## 三种形式速查

| 转换 | 公式 |
|------|------|
| 直角 → 极角 | $r=\sqrt{a^2+b^2},\ \theta=\tan^{-1}\frac{b}{a}$ |
| 极角 → 直角 | $a=r\cos\theta,\ b=r\sin\theta$ |
| 极角 ↔ 指数 | $r\angle\theta = re^{j\theta}$ |
| 正弦 → 相量 | $V_m\cos(\omega t+\phi) \rightarrow V_m\angle\phi$ |
| 相量 → 正弦 | $V_m\angle\phi \rightarrow V_m\cos(\omega t+\phi)$ |
| 共轭 | $r\angle\theta \rightarrow r\angle(-\theta)$ |
| 倒数 | $\frac{1}{r\angle\theta} \rightarrow \frac{1}{r}\angle(-\theta)$ |
