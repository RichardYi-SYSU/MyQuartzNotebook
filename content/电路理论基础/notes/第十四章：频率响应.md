
## 14.1 传递函数

### 定义

$$H(\omega) = \frac{Y(\omega)}{X(\omega)} = \frac{\text{响应(输出)}}{\text{激励(输入)}}$$

$H(\omega)$ 是一个复数量：$H(\omega) = |H(\omega)|\angle\phi$

### 四种传递函数类型

| 类型 | 表达式 | 名称 |
|------|--------|------|
| $H(\omega) = V_o/V_i$ | 电压增益 | Voltage gain |
| $H(\omega) = I_o/I_i$ | 电流增益 | Current gain |
| $H(\omega) = V_o/I_i$ | 转移阻抗 | Transfer Impedance |
| $H(\omega) = I_o/V_i$ | 转移导纳 | Transfer Admittance |

### 标准形式

$$H(\omega) = \frac{N(\omega)}{D(\omega)} \quad\text{（最简多项式之比）}$$

- **零点**：$N(\omega)=0$ 的根，$H=0$
- **极点**：$D(\omega)=0$ 的根，$H\to\infty$

## 14.2 分贝表示法

$$G_{dB} = 10\log_{10}\frac{P_2}{P_1} \quad\text{（功率）}$$

$$G_{dB} = 20\log_{10}\frac{V_2}{V_1} = 20\log_{10}\frac{I_2}{I_1} \quad\text{（电压/电流）}$$

> 功率用 $10\log$，电压/电流用 $20\log$（因为功率 $\propto$ 电压/电流的平方）。

| 分贝值 | 含义 |
|--------|------|
| 0 dB | 增益 = 1 |
| 3 dB | 增益 $\approx$ 1.414（半功率点） |
| -3 dB | 增益 $\approx$ 0.707（截止频率处） |
| 20 dB | 增益 = 10 |
| -20 dB | 增益 = 0.1 |

## 14.4 串联谐振电路

### 谐振条件

$$Z = R + j\left(\omega L - \frac{1}{\omega C}\right)$$

谐振时 $\operatorname{Im}(Z)=0$：

$$\omega_0 L = \frac{1}{\omega_0 C} \quad\Rightarrow\quad \omega_0 = \frac{1}{\sqrt{LC}}$$

$$f_0 = \frac{1}{2\pi\sqrt{LC}}$$

### 谐振性质

| 频率范围 | 电路性质 |
|----------|----------|
| $\omega < \omega_0$ | 容性 |
| $\omega = \omega_0$ | 纯阻 ($Z=R$) |
| $\omega > \omega_0$ | 感性 |

### 品质因数

$$Q = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 CR} = \frac{\rho}{R}$$

其中 $\rho = \omega_0 L = 1/\omega_0 C$ 为**特征阻抗**。

### 电压谐振

$$V_L = I\omega_0 L = \frac{V_m}{R}\omega_0 L = QV_m$$

$$V_C = I\frac{1}{\omega_0 C} = QV_m$$

> $V_L$ 和 $V_C$ 可达电源电压的 $Q$ 倍，互相抵消（大小相等、相位相反）。

### 带宽与半功率频率

$$B = \omega_2 - \omega_1 = \frac{R}{L} = \frac{\omega_0}{Q}$$

$$\omega_1 = -\frac{R}{2L} + \sqrt{\left(\frac{R}{2L}\right)^2 + \frac{1}{LC}}$$

$$\omega_2 = \frac{R}{2L} + \sqrt{\left(\frac{R}{2L}\right)^2 + \frac{1}{LC}}$$

$$\omega_0 = \sqrt{\omega_1\omega_2}$$

**高 Q 电路 ($Q \geq 10$)** 近似：
$$\omega_1 \approx \omega_0 - \frac{B}{2},\quad \omega_2 \approx \omega_0 + \frac{B}{2}$$

### 五个表征参数

$\omega_1$、$\omega_2$、$\omega_0$、$B$、$Q$，知其二可推其余。

## 14.5 并联谐振电路

### 输入导纳

$$Y = \frac{1}{R} + j\left(\omega C - \frac{1}{\omega L}\right)$$

谐振时 $\operatorname{Im}(Y)=0$：$\omega_0 = 1/\sqrt{LC}$（同串联）

### 电流谐振

$$I_L = \frac{I_m R}{\omega_0 L} = QI_m,\quad I_C = \omega_0 C I_m R = QI_m$$

### 参数公式

| 参数 | 公式 |
|------|------|
| 品质因数 | $Q = \dfrac{R}{\omega_0 L} = \omega_0 RC$ |
| 带宽 | $B = \dfrac{1}{RC}$ |
| 半功率频率 | $\omega_1 = -\dfrac{1}{2RC} + \sqrt{\left(\dfrac{1}{2RC}\right)^2 + \dfrac{1}{LC}}$ |

### 串/并联谐振对比

| 特性 | 串联谐振 | 并联谐振 |
|------|---------|---------|
| $\omega_0$ | $1/\sqrt{LC}$ | $1/\sqrt{LC}$ |
| $Q$ | $\omega_0 L/R = 1/(\omega_0 CR)$ | $R/(\omega_0 L) = \omega_0 RC$ |
| $B$ | $R/L$ | $1/(RC)$ |
| 谐振时阻抗 | 最小 ($Z=R$) | 最大 ($Z=R$) |
| 谐振现象 | 电压谐振 ($V_L=V_C=QV$) | 电流谐振 ($I_L=I_C=QI$) |
| 半功率公式 | $\omega_0\sqrt{1+(1/2Q)^2} \pm \omega_0/(2Q)$ | 同左 |
| Q≥10 时 $\omega_{1,2}$ | $\omega_0 \pm B/2$ | $\omega_0 \pm B/2$ |
| $\omega_0 = \sqrt{\omega_1\omega_2}$ | ✓ | ✓ |

## 14.6 无源滤波器

### 四种滤波器

| 类型 | 功能 | $H(0)$ | $H(\infty)$ | 关键频率处 $H$ |
|------|------|--------|------------|---------------|
| 低通 | 低频通过，高频阻止 | 1 | 0 | $H(\omega_c)=1/\sqrt{2}$ |
| 高通 | 高频通过，低频阻止 | 0 | 1 | $H(\omega_c)=1/\sqrt{2}$ |
| 带通 | $\omega_1<\omega<\omega_2$ 通过 | 0 | 0 | $H(\omega_0)=1$ |
| 带阻 | $\omega_1<\omega<\omega_2$ 阻止 | 1 | 1 | $H(\omega_0)=0$ |

### 低通滤波器（RC）

输出取自电容两端：

$$H(\omega) = \frac{1}{1+j\omega RC}, \quad \omega_c = \frac{1}{RC}$$

- 截止频率 $\omega_c$ 处：$|H|=1/\sqrt{2}\approx 0.707$（-3 dB，半功率点）
- 只允许 $0 \to \omega_c$ 的频率通过

### 高通滤波器（RC）

输出取自电阻两端：

$$H(\omega) = \frac{j\omega RC}{1+j\omega RC}, \quad \omega_c = \frac{1}{RC}$$

### 带通滤波器（RLC 串联）

输出取自电阻两端：

$$H(\omega) = \frac{R}{R + j(\omega L - 1/\omega C)}, \quad \omega_0 = \frac{1}{\sqrt{LC}}$$

带宽 $B = \omega_2 - \omega_1 = R/L$

### 带阻滤波器（RLC 串联）

输出取自 LC 串联组合两端：

$$H(\omega) = \frac{j(\omega L - 1/\omega C)}{R + j(\omega L - 1/\omega C)}$$

> 无源滤波器最大增益为 1（无放大）。增益 > 1 需用有源滤波器。

## 14.7 有源滤波器（了解）

| 滤波器 | 结构 | 截止/中心频率 |
|--------|------|-------------|
| 一阶低通 | 反相放大器的 $R_f$ 并联 $C_f$ | $\omega_c = 1/(R_f C_f)$ |
| 一阶高通 | 输入端串联 RC（$R_i, C_i$） | $\omega_c = 1/(R_i C_i)$ |
| 带通 | 低通 + 高通级联 | — |
| 带阻 | 低通和高通并联后求和放大 | — |

## 题型与解题策略

### 题型一：求传递函数与零点/极点

**特征**：给定电路，求 $H(\omega)=V_o/V_i$ 及零极点。

**策略**：
1. 频域电路 → 分压/分流或 KVL/KCL
2. 化简为 $H(\omega) = N(\omega)/D(\omega)$ 标准式
3. 零点：$N(\omega)=0$；极点：$D(\omega)=0$

> 参考：PPT 例 14-1（RC 低通）、例 14-2（零点极点）
> 作业：14.4

---

### 题型二：串联/并联谐振参数计算

**特征**：已知 $R,L,C$，求 $\omega_0$、$Q$、$B$、$\omega_1$、$\omega_2$、谐振时电流/电压。

**策略**：
1. $\omega_0 = 1/\sqrt{LC}$
2. 串联 $Q = \omega_0 L/R$，并联 $Q = R/(\omega_0 L)$
3. $B = \omega_0/Q$
4. $Q \geq 10$ 时：$\omega_{1,2} \approx \omega_0 \pm B/2$
5. $Q < 10$ 时：用精确公式
6. 谐振时 $I = V_m/R$（串联），半功率点 $I = V_m/(\sqrt{2}R)$

> 参考：PPT 例（串联谐振例题）
> 作业：14.30、14.42

---

### 题型三：滤波器类型判断与截止频率

**特征**：给定电路结构，判断滤波器类型，求截止/中心频率。

**策略**：
1. 求 $H(\omega)$
2. 看 $H(0)$ 和 $H(\infty)$ 判断类型：
   - $H(0)=1, H(\infty)=0$ → 低通
   - $H(0)=0, H(\infty)=1$ → 高通
   - $H(0)=0, H(\infty)=0$ → 带通
   - $H(0)=1, H(\infty)=1$ → 带阻
3. 低通/高通：令 $|H(\omega_c)|=1/\sqrt{2}$ 求 $\omega_c$
4. 带通/带阻：$\omega_0 = 1/\sqrt{LC}$

> 参考：PPT 例（RLC 低通判断）、带阻滤波器设计
> 作业：14.48、14.55
