
## 判断组序

都用相量形式表示，找到中间的那个相量，其+120得到的那个就是组序中的第一个，自己就是中间那个，-120得到的就是组序中的最后一个

是循环顺序：c->b->a 就是a->c->b

## 两种负载连接方式

| 项目       | Y 形联结              | Δ 形联结             |
| -------- | ------------------ | ----------------- |
| 结构       | 三个阻抗一端连在一起         | 三个阻抗首尾相接          |
| 是否有中性点   | 有                  | 无                 |
| 每相负载接在哪里 | 相线与中性点之间           | 两根相线之间            |
| 相电压关系    | $U_P=U_L/\sqrt{3}$ | $U_P=U_L$         |
| 相电流关系    | $I_L=I_P$          | $I_L=\sqrt{3}I_P$ |
| 常见特点     | 每个负载承受电压较低         | 每个负载承受线电压         |

## 线电压和相电压

| 接法  | 相电压是什么      | 线电压是什么  | 关系                |
| --- | ----------- | ------- | ----------------- |
| Y 接 | 相线对中性点电压    | 两相线之间电压 | $U_L=\sqrt{3}U_P$ |
| Δ 接 | 每个绕组/负载两端电压 | 两相线之间电压 | $U_L=U_P$         |

**线电压不是某一个相电压，而是两个相电压的相量差。**

例如：
$$V_{ab}=V_{an}-V_{bn}$$

因为三相相电压之间差 120∘120^\circ120∘，所以相量相减后得到的线电压：

大小变成 \sqrt{3} 倍，角度相对相电压偏移 30

对于正相序：

$$V_{ab}=\sqrt{3}V_{an}\angle 30^\circ$$

$$V_{bc}=\sqrt{3}V_{bn}\angle 30^\circ$$

$$V_{ca}=\sqrt{3}V_{cn}\angle 30^\circ$$

也就是：**正相序 Y 接中，线电压超前对应相电压30度**

## 线电流和相电流

> **线电流** $I_L$：流过每根火线的电流。**相电流** $I_P$：流过每相负载/绕组的电流。

### Y 形联结

Y 接中，每相负载串联在火线与中性点之间，**线电流 = 相电流**：

$$I_L = I_P$$

即 $I_a = I_{AN},\ I_b = I_{BN},\ I_c = I_{CN}$。

对称时：$I_a + I_b + I_c = 0$，**中性线电流为零**，可移除中性线而不影响电路。

### Δ 形联结

Δ 接中，每相负载跨接在两根火线之间，线电流等于两相邻相电流的**相量差**（由 KCL 导出）：

$$I_a = I_{AB} - I_{CA}$$
$$I_b = I_{BC} - I_{AB}$$
$$I_c = I_{CA} - I_{BC}$$

由于三相相电流互差 $120^\circ$，相减后得到：

$$I_L = \sqrt{3}\,I_P$$

且**线电流滞后对应相电流 $30^\circ$**（正序）：

$$I_a = \sqrt{3}\,I_{AB}\angle(-30^\circ)$$

[[电路理论基础/materials/pdfs/第12章三相电路（2026.6.8）.pdf#page=34|第12章三相电路（2026.6.8）, 页面 34]] 由于是正序，因此AB->BC->CA 分别滞后120 120+120（也就是-240 -> +120）
### 线/相电压电流关系汇总

| 关系 | Y 形联结 | Δ 形联结 |
|------|---------|---------|
| 线电压 $U_L$ vs 相电压 $U_P$ | $U_L = \sqrt{3}\,U_P$（超前 $30^\circ$） | $U_L = U_P$ |
| 线电流 $I_L$ vs 相电流 $I_P$ | $I_L = I_P$ | $I_L = \sqrt{3}\,I_P$（滞后 $30^\circ$） |
| 中性点 | 有 | 无 |
| 适用电压形式 | 可提供两种电压（$380/220$V） | 仅提供一种电压 |

> **记忆口诀**：Y 接——线压大、流相等；Δ 接——线压等、流大 $\sqrt{3}$。

## 四种电源-负载连接方式

| 连接方式 | 特点 | 常用程度 |
|----------|------|----------|
| Y-Y | 最常见，可单相等效分析 | ★★★★★ |
| Y-Δ | 需先 Δ→Y 转换或直接用线电压求相电流 | ★★★★ |
| Δ-Y | 源和负载都转为 Y 后单相分析 | ★★★ |
| Δ-Δ | 线电压=相电压，直接求相电流 | ★★ |

| 组合          |         负载相电压 (U_\phi) |               负载相电流 (I_\phi) |                    线电流 (I_L) |
| ----------- | ---------------------: | ---------------------------: | ---------------------------: |
| Y 电源 — Y 负载 | $\frac{U_L}{\sqrt{3}}$ | $\frac{U_L}{\sqrt{3}Z_\phi}$ | $\frac{U_L}{\sqrt{3}Z_\phi}$ |
| Y 电源 — Δ 负载 |                    $U_L$ |         $\frac{U_L}{Z_\phi}$ | $\sqrt{3}\frac{U_L}{Z_\phi}$ |
| Δ 电源 — Y 负载 | $\frac{U_L}{\sqrt{3}}$ | $\frac{U_L}{\sqrt{3}Z_\phi}$ |   $\frac{U_L}{\sqrt{3}Z_\phi}$ |
| Δ 电源 — Δ 负载 |                    $U_L$ |           $\frac{U_L}{Z_\phi}$ |   $\sqrt{3}\frac{U_L}{Z_\phi}$ |

## 对称三相电路的单相分析法

对于**对称 Y-Y 系统**（忽略线路阻抗），只需分析其中**一相**，其余两相按 $\pm 120^\circ$ 得出：

$$I_a = \frac{V_{an}}{Z_Y},\quad I_b = I_a\angle(-120^\circ),\quad I_c = I_a\angle(+120^\circ)$$

若为 Y-Δ 系统，先将 Δ 负载转为等效 Y 负载：

$$Z_Y = \frac{Z_{\Delta}}{3}$$

## 对称三相电路的功率

无论 Y 接还是 Δ 接，三相总功率公式统一为：

| 功率类型 | 公式 |
|----------|------|
| 有功功率 $P$ | $P = \sqrt{3}\,U_L I_L \cos\varphi$ |
| 无功功率 $Q$ | $Q = \sqrt{3}\,U_L I_L \sin\varphi$ |
| 视在功率 $S$ | $S = \sqrt{3}\,U_L I_L$ |

> $\varphi$ 是**每相负载的阻抗角**（$U_P$ 与 $I_P$ 的相位差），不是 $U_L$ 与 $I_L$ 的相位差。

也可用相电压、相电流表示：
$$P = 3U_P I_P \cos\varphi = 3I_P^2 R_P$$

> 对称三相系统的**瞬时总功率为恒定值**（不脉动），这是三相电优于单相电的关键特性。

## 计算示例

### 例1：Y-Y 对称系统

> 对称 Y 接负载，线电压 $380$V，每相 $Z = 6.4 + j4.8\,\Omega$。求 $U_P$、$I_P$、$I_L$、$P$。

1. 相电压：$U_P = U_L/\sqrt{3} = 380/\sqrt{3} \approx 220$ V
2. 阻抗模：$|Z| = \sqrt{6.4^2 + 4.8^2} = 8\,\Omega$
3. 相电流：$I_P = U_P/|Z| = 220/8 = 27.5$ A
4. 线电流：$I_L = I_P = 27.5$ A（Y 接）
5. 功率因数：$\cos\varphi = R/|Z| = 6.4/8 = 0.8$
6. 总有功：$P = \sqrt{3} \times 380 \times 27.5 \times 0.8 \approx 14.52$ kW

### 例2：Δ-Δ 对称系统

> 对称 Δ 接负载，线电压 $380$V，每相 $Z = 6 + j8\,\Omega$。求 $U_P$、$I_P$、$I_L$、$P$。

1. 相电压：$U_P = U_L = 380$ V（Δ 接）
2. 阻抗模：$|Z| = \sqrt{6^2 + 8^2} = 10\,\Omega$
3. 相电流：$I_P = U_P/|Z| = 380/10 = 38$ A
4. 线电流：$I_L = \sqrt{3}\,I_P \approx 1.732 \times 38 \approx 65.82$ A（Δ 接）
5. 功率因数：$\cos\varphi = 6/10 = 0.6$
6. 总有功：$P = \sqrt{3} \times 380 \times 65.82 \times 0.6 \approx 26.64$ kW
